> **Sagar Utekar** | CNCF Ambassador | Kubestronaut

## What You Will Learn

AI-powered shell script generation, fixing, conversion, explanation, and optimization — every SRE's secret weapon for automating faster and safer.

---

## 5 Tasks

| Task | Name | What You Learn |
|------|------|----------------|
| 1 | Script Generator | Natural language → complete shell scripts with error handling |
| 2 | Script Fixer | Paste broken scripts → AI diagnoses and fixes them |
| 3 | Script Converter | Convert bash → Python with idiomatic error handling |
| 4 | Script Explainer | AI explains complex one-liners and pipelines step by step |
| 5 | Script Optimizer | AI adds safety guards, error handling, and performance improvements |

All tasks use real SRE scenarios — disk monitoring, log rotation, deployment scripts, health checks. No "hello world."
